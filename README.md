# 🧾 AI 环境台账（ai-env-ledger）

记录本机 AI 助手环境的**每一次安装、配置与移除**——什么时候装的、装了什么、为什么装、状态如何。
由 WorkBuddy 助手维护，增删组件时同步更新此仓库，做到**可追溯、可复现、可回滚**。

## 🔒 安全约定（重要）

- **本仓库绝不存放任何明文凭据**：GitHub Token、Twitter Cookie、雪球 Cookie、代理密码一律只记「存放路径」，不记内容。
- 见 `inventory/` 中各文件的「凭据位置」字段；`scripts/` 内脚本运行时从本地文件读取，不硬编码密钥。
- `.gitignore` 已屏蔽 `*.env`、`*token*`、`*cookie*` 等敏感文件名模式。

## 🔄 更新规则

每完成一次环境变更（安装、升级、删除），必须做两件事：

1. 在 `CHANGELOG.md` **顶部**追加一条记录，字段：`日期 / 操作 / 对象 / 版本 / 用途 / 状态 / 备注`
2. 同步更新对应的 `inventory/*.md` 清单

状态标记约定：

| 标记 | 含义 |
|---|---|
| ✅ 可用 | 已验证正常工作 |
| ⚠️ 部分可用 | 已装但有前置条件（需登录/代理/密钥） |
| ❌ 不可用 | 已装但当前跑不通 |
| 🗑 已移除 | 曾安装，现已删除（保留记录以便回溯） |

---

## 🚀 环境复现

若换机器或重装系统，按 `CHANGELOG.md` **从旧到新**逆序执行即可完整还原当前环境。
各条目均附带安装命令与配置文件路径。
